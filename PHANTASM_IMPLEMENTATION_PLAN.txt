Hours 5–9: sm_core.py — NFQueue Hook + Service Dispatch

  NFQueue integration:
    import nfqueue
    from scapy.all import IP, TCP, UDP, Raw

    q = nfqueue.queue()
    q.open()
    q.bind(socket.AF_INET)
    q.set_callback(packet_handler)
    q.fast_open(NFQUEUE_QUEUE_NUM, socket.AF_INET)
    q.try_run()

  packet_handler(payload):
    data = payload.get_data()
    pkt = IP(data)
    dst_ip = pkt.dst
    dst_port = pkt[TCP].dport if TCP in pkt else (pkt[UDP].dport if UDP in pkt else None)

    host = topology.get_host_by_ip(dst_ip)  # O(1) dict lookup
    if host is None:
      payload.set_verdict(nfqueue.NF_DROP)
      return

    # Apply latency jitter
    baseline = host.latency_baseline_ms
    jitter = random.gauss(baseline, baseline * host.latency_jitter_pct)
    time.sleep(max(0, jitter) / 1000.0)

    # Dispatch to service emulator
    response = service_registry.dispatch(host, pkt)
    if response:
      # Craft response packet with Scapy and re-inject
      # Swap src/dst, set correct TTL
      resp_pkt = craft_response(pkt, response, host)
      send(resp_pkt, verbose=0)
      payload.set_verdict(nfqueue.NF_DROP)  # We handle it manually
    else:
      payload.set_verdict(nfqueue.NF_ACCEPT)

    # Publish event to Redis
    event = build_event(pkt, host, response)
    redis_client.publish("sm:events", json.dumps(event))

Hours 3–6: mt_classifier.py — ONNX Inference Wrapper

  class ATTACKClassifier:
    __init__(model_path, label_map_path, keyword_map_path):
      self.ort_session = ort.InferenceSession(model_path,
        providers=['CPUExecutionProvider'])
      self.tokenizer = AutoTokenizer.from_pretrained(tokenizer_path)
      with open(label_map_path) as f: self.label_map = json.load(f)
      with open(keyword_map_path) as f: self.keyword_map = json.load(f)

    classify(command_text: str) → List[TechniqueResult]:
      # Normalise
      text = command_text.lower().strip()[:512]

      # ONNX inference path
      try:
        inputs = self.tokenizer(text, return_tensors="np", padding=True,
                                truncation=True, max_length=128)
        start = time.time()
        logits = self.ort_session.run(None, {
          "input_ids": inputs["input_ids"],
          "attention_mask": inputs["attention_mask"]
        })[0][0]
        inference_ms = (time.time() - start) * 1000
        log_perf(inference_ms)  # Track in performance.log

        probs = 1 / (1 + np.exp(-logits))  # Sigmoid
        results = []
        for i, prob in enumerate(probs):
          if prob > 0.5:  # Primary threshold
            results.append(TechniqueResult(
              technique_id=self.label_map[str(i)],
              confidence=float(prob), is_primary=True))
          elif prob > 0.3:  # Secondary threshold
            results.append(TechniqueResult(
              technique_id=self.label_map[str(i)],
              confidence=float(prob), is_primary=False))

        if results: return results

      except Exception as e:
        logger.warning(f"ONNX inference failed: {e}. Falling back to keywords.")

      # Keyword fallback — always runs if ONNX returns nothing or fails
      return self._keyword_classify(text)

    _keyword_classify(text) → List[TechniqueResult]:
      results = []
      for technique_id, keywords in self.keyword_map.items():
        for kw in keywords:
          if kw in text:
            results.append(TechniqueResult(
              technique_id=technique_id, confidence=0.65, is_primary=True))
            break
      return results or [TechniqueResult("UNKNOWN", 0.0, False)]

Hours 6–9: mt_expertise.py + mt_timing.py + mt_attribution.py

  mt_expertise.py — ExpertiseScorer:
    Maintain running score (only ever increases within session).
    score_command(command_text, technique_results) → (score_delta, new_total):
      Apply all 4 scoring signal categories (TRD Section 8.4):
        command_complexity_score = count_pipes*5 + count_flags*3 + subshell*10 +
                                   redirection*3 + base64_detected*15
        tool_sophistication_score: map command prefix to tool tier (TRD Section 8.4)
        sequencing_score: track last 5 techniques and check for logical progression
        privesc_speed_score: track how quickly first privesc attempt occurs
      weighted_delta = (0.30*cmd + 0.30*tool + 0.20*seq + 0.20*privesc)
      Update running total.
    get_level(score) → ('script_kiddie'|'intermediate'|'advanced'|'apt_grade', score):
      Threshold map from TRD Section 8.4: 0/25/50/75

  mt_timing.py — TimingAnalyser:
    Maintain deque(maxlen=20) of ICI values.
    update(new_ici_ms) → operational_state:
      ici_window.append(new_ici_ms)
      mean_ici = statistics.mean(ici_window)
      stddev = statistics.stdev(ici_window) if len > 1 else 0
      trend = float(np.polyfit(range(len(ici_window)), list(ici_window), 1)[0])
      (state logic from TRD Section 8.6)
    is_stress_event(prev_ici, new_ici) → (bool, annotation_str):
      return (prev_ici > 8000 and new_ici < 3000,
              f"Stress onset — cadence +{((prev_ici/new_ici)-1)*100:.0f}%")

  mt_attribution.py — AttributionScorer:
    __init__: load group_vectors.npy and group_names.json on init.
    score(technique_id_list) → List[GroupMatch]:
      Build session_vector from technique_id_list (count-normalised).
      scores = cosine_similarity(session_vector.reshape(1,-1), self.group_vectors)
      top5 = sorted indices by score descending, take top 5.
      return [GroupMatch(group_id, name, score) for each of top5]

Hours 9–12: mt_engine.py — Integration + Redis Pipeline

  Main async process:
    - Subscribe to Redis "sm:events"
    - Maintain in-memory profile state: {session_id → ProfileState}
    - On each command event:
        1. Compute ICI (ms since previous command for this session)
        2. Run ATTACKClassifier.classify(command_text) → techniques
        3. Run ExpertiseScorer.score_command() → expertise update
        4. Run TimingAnalyser.update(ici_ms) → operational_state
        5. Check is_stress_event() → flag command if stress trigger
        6. Every 5th command: run AttributionScorer.score() → attribution
        7. Build profile_update dict from all current state
        8. Publish to "mt:profile" channel
        9. Write command + techniques to SQLite (via async queue to flush worker)
        10. Write stress_timeline row if stress_state != 'normal'
        11. Write operator_profiles row every 5 commands

  Flush worker (background coroutine, runs every 5 seconds):

5.5 FAILURE RECOVERY PROCEDURES (all members must memorise)
────────────────────────────────────────────────────────────────────────────────

  SCENARIO — NFQueue stops responding:
    sudo iptables -D INPUT -i shadowmesh0 -j NFQUEUE --queue-num 1
    sudo iptables -I INPUT -i shadowmesh0 -j NFQUEUE --queue-num 1
    pkill -f sm_core.py && sudo python backend/sm_core.py &
    Recovery: ~30 seconds

  SCENARIO — Redis crashes:
    docker-compose restart redis
    All components auto-reconnect (retry backoff: 1s→2s→4s)
    Recovery: ~10 seconds

  SCENARIO — BERT too slow during demo:
    In mt_engine terminal: Ctrl+C
    Edit: USE_KEYWORD_FALLBACK_ONLY=True in mt_engine.py
    python backend/mt_engine.py &
    Recovery: ~10 seconds. Classification continues, slightly less accurate.

  SCENARIO — WebSocket drops:
    Socket.io auto-reconnects in 3-5 seconds. No action needed.
    If does not reconnect: browser refresh. State restores via "request_snapshot".

  SCENARIO — Claude API fails during dossier generation:
    Cached fallback fires automatically if API call fails or times out.
    Dossier PDF still generates from cached narrative.
    Judge does not see a difference in the output.

  SCENARIO — React dashboard crashes (white screen):
    Browser refresh. Socket.io reconnects. Request "request_snapshot" fires.
    If still broken: switch to pre-built production serve (npx serve -s dist).
