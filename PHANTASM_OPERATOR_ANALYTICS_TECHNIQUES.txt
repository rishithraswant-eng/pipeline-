1. MITRE ATT&CK TECHNIQUE MAPPING (attck_mapper.py)
--------------------------------------------------------------------------------
PHANTASM inspects incoming shell commands and maps them directly to official
MITRE ATT&CK framework IDs:

Technique ID | MITRE Name                       | Trigger Keywords                 | Threat Category
-------------+----------------------------------+----------------------------------+----------------------------------
T1046        | Network Service Discovery        | nmap                             | Port & service scanning
T1003        | OS Credential Dumping            | mimikatz, sekurlsa, lsadump      | Extracting LSASS / SAM passwords
T1490        | Inhibit System Recovery          | vssadmin, shadow, backup         | Wiping volume shadow copies
T1486        | Data Encrypted for Impact        | encrypt                          | Ransomware execution
T1053        | Scheduled Task/Job               | schtasks                         | Establishing persistence
T1021        | Remote Services                  | net use                          | SMB / NetBIOS lateral movement
T1005        | Data from Local System           | select                           | SQL queries & data exfiltration
T1087        | Account Discovery                | net, get-aduser                  | Enumerating AD / local users
T1105        | Ingress Tool Transfer            | curl                             | Downloading external payloads
T1083        | File and Directory Discovery     | dir                              | File system reconnaissance
T1016        | System Network Config Discovery  | ipconfig                         | Adapter & IP discovery
T1018        | Remote System Discovery          | ping                             | Network ping sweeps
T1059        | Command & Scripting Interpreter  | (Default fallback)               | Generic shell execution


2. OPERATOR EXPERTISE CLASSIFICATION (classifier.py)
--------------------------------------------------------------------------------
Commands are evaluated using heuristic keyword scoring across syntax complexity,
tool sophistication, and encoding techniques:

- Script Kiddie (Score < 15):
  Runs basic built-in commands (dir, ipconfig, net).

- Intermediate (15 <= Score < 35):
  Uses shell piping (|), output redirection (>), file transfers.

- Advanced (35 <= Score < 60):
  Uses base64 encoding (-enc), subshell execution ($()), scanners (nmap, mimikatz).

- APT - Advanced Persistent Threat (Score >= 60):
  Uses C2 frameworks (cobaltstrike, powersploit, empire), advanced privilege 
  escalation, & evasion mechanisms.


3. OPERATIONAL & STRESS STATE MACHINE (stress_detector.py)
--------------------------------------------------------------------------------
Calculates Inter-Command Intervals (ICI) — the time gap (in milliseconds) between 
consecutive commands across a rolling 20-command window:

State        | Criteria                                 | Operational Meaning
-------------+------------------------------------------+--------------------------------------
automated    | Mean ICI < 500ms                         | Scripted bot / automated execution
disoriented  | Std Dev > 3000ms                         | High hesitation, trial-and-error
stressed     | Mean ICI < 2000ms & Std Dev > 800ms      | Rapid, erratic typing under pressure
methodical   | 2000ms <= Mean ICI <= 8000ms, Std < 1000 | Calm, systematic human operator
exploratory  | Default / Initial (< 20 commands)        | Initial discovery phase


4. ENGAGEMENT SCORE FORMULA (profile_engine.py)
--------------------------------------------------------------------------------
The honeypot engagement score (0 to 100) measures how deeply the attacker is 
engaged in the deception environment:

  Engagement Score = Min(100, (Unique Techniques * 15) + (Avg Confidence * 30) + (Dwell Mins * 2))

This score determines when to trigger dynamic ShadowMesh network mutations to 
keep the threat actor trapped longer.
